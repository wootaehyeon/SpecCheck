# Windows Agent의 진단·구매 지원

구현·검증일: 2026년 11월 10일(KST).

## 동작

1. Agent가 현재 회차의 스냅샷 전송을 완료하면 해당 스캔 ID로 자신의 진단을 요청한다.
2. 유지·수정·구매 판정을 확인하고, 구매 판정에 연결된 검증 가능한 후보를 모은다.
3. 추천 창에서 후보 사양, 호환 검사 결과와 추가 확인 사항을 표시한다.
4. 사용자가 추천 창을 열거나 갱신하면 카탈로그 ID만으로 서버 가격 API를 호출한다.
5. 가격 조회가 실패하면 기술적 후보와 검색 링크를 유지하고 미확인으로 안내한다.
6. 사용자가 선택한 판매처를 열거나 공개 구매이력 웹을 열 수 있다. 결제는 판매처에서 진행한다.

Agent는 작업 흐름을 조정하고 서버의 규칙 엔진·카탈로그·가격 도구를 재사용한다.
LLM이 실행 단계를 자율 계획하는 에이전트로 변경한 것은 아니다.
자동 기술 추천 확인은 약 5분 간격이고 가격 조회는 사용자의 추천 창 열기·갱신 시 수행한다.
30초 성능 수집·전송과 추천 작업은 별도 스레드로 동작한다.

## 변경 지점

- `agent/speccheck_agent/purchase.py`: 자신의 진단 조회, 구매 여부 분기, 후보 필터링,
  판매 정보 조회, 미확인 처리와 허용된 판매처 링크 생성.
- `agent/speccheck_agent/desktop.py`: 추천 창, 판매처 선택·열기, 공개 이력 열기,
  연결 세대·요청 ID를 사용한 이전 응답 배제.
- `agent/speccheck_agent/watch.py`: 현재 회차의 업로드 성공 시 스캔 ID 전달.
- `GET /api/monitor/assistance`: 전송키로 자신의 최근 7일 진단과 교체 후보만 조회.
  다른 PC, 만료 자료, 원시 스냅샷·이벤트·조회키 조회를 허용하지 않는다.
  기존 `/latest`, `/history`, `/process-events`의 조회키 인증은 유지한다.

## 검증

- Agent 회귀: 146건 통과. 추천 분기, 가격 실패·응답 형식 오류, 호환 실패 제외,
  기기·스캔 불일치, 링크·인증키 처리, GUI 새로고침·판매처 열기·이전 응답 배제를 포함한다.
- Backend 회귀: 303건 통과. 새 API의 기기·키 권한 분리, 자료 만료와 진단 실패를 포함한다.
- UI 로직 회귀: 53건 통과.
- 실제 로컬 Docker API와 Agent 코드 연동: 합성 유지·수정·구매 3개 사례에서
  구매 링크 0·0·6개를 확인하고 생성한 연결을 삭제했다. 실제 사용자 PC 정보는 수집하지 않았다.
- 실제 서버를 호출하는 Python GUI의 추천 표시와 서버 다운로드 EXE의 SHA-256 일치를 확인했다.
- Python GUI의 `--smoke-test` 통과. 최종 Windows EXE는 빌드됐으나 이 PC의
  Windows Application Control 정책이 실행을 차단하여 최종 바이너리 실행 검증은 완료하지 못했다.
  정책 변경이나 차단 우회는 수행하지 않았다.

## 로컬 실행

로컬 Docker 서버에 변경을 반영했다. 기존 데이터 볼륨을 유지했다.
브라우저에서 `http://127.0.0.1:8000/monitor.html`을 열어 새 연결 코드를 발급한다.
프로젝트의 `agent` 디렉터리에서 아래 명령으로 GUI를 실행할 수 있다.

```powershell
..\.venv\Scripts\python.exe -m speccheck_agent.desktop
```

Agent의 서버 주소를 `http://127.0.0.1:8000`으로 맞추고 코드를 입력한 뒤
첫 데이터 전송 후 **진단·구매 추천 보기**를 누른다.
이전에 공개 서버 연결이 저장되어 있으면 새 코드와 로컬 서버 주소로 연결해야 한다.

EXE와 빌드 정보는 `agent/releases/`에 있다. 이번 빌드는 로컬 서버 주소를 기본값으로 포함한다.
공개 Render 서버에는 배포하지 않았다. 공개 서비스 사용에는 서버 업데이트와 해당 주소를
기본값으로 한 EXE 재빌드가 필요하다. 실제 판매 가격은 서버의 공급자 인증 상태에 의존한다.
