# 부품 호환성 자료

TechFuelHQ PC Builder Parts Dataset (CC BY 4.0).
https://techfuelhq.com/tools/pc-builder/

원본: https://github.com/iBlessi/pc-builder-parts

- `techfuelhq/`: 라이선스 포함 원본 자료. 개별 출처가 없는 부품도 있어 원본 전체를 검증된 추천 후보로 취급하지 않는다.
- `manufacturer-boards.json`: 제조사 페이지에서 확인한 추가 사양 사실과 출처.
- `gemma/`: 프로그램으로 생성한 합성 학습·평가 사례. 사람 검토 전이며 Gemma 가중치 학습은 수행하지 않았다.

운영 자료는 필요한 사실만 추출·정규화한 파생 자료다. 자유 서술 의견과 가격은 추천 지식에 포함하지 않는다. 자세한 적용 범위와 재생성 방법은 [설명 문서](../../docs/GEMMA_COMPATIBILITY.md)를 참고한다.
