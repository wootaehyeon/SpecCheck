내 PC 연결

웹페이지는 PC 정보를 직접 읽지 않습니다. 본인의 Windows PC에서 Agent를 실행하면 여기에 표시됩니다.

  1. 연결 설정 저장아래 항목에 동의하고 내 PC 연결을 누르세요.
  2. Agent 다운로드ZIP 압축을 풀고 연결 설정 파일을 같은 폴더에 넣으세요.
  3. PC에서 실행Python 3.10 이상이 필요합니다. Start-SpecCheck.cmd를 실행하고 Y를 눌러 시작하세요.

서버 이력은 7일, 연결키는 90일 동안 유지됩니다. 브라우저에 조회키를 저장하며, 연결 해제로 서버 이력과 키를 삭제할 수 있습니다. Agent를 중단해도 로컬 원본은 PC에 남습니다.
